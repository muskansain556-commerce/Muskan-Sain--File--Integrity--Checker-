# GitHub App Upload Guide (Hinglish) — Muskan Sain

## A. GitHub par repository banana
1. GitHub app open karo aur apne account mein sign in karo.
2. Neeche ya profile/menu mein **Repositories** section kholo.
3. **+** ya **Create repository** option select karo. Agar app mein option na dikhe, mobile browser mein github.com open karke same account se login karo.
4. Repository name likho: `file-integrity-checker`.
5. Description likho: `SHA-256 based File Integrity Checker — Cybersecurity Project by Muskan Sain`.
6. Repository ko **Public** ya faculty ke instruction ke hisaab se **Private** rakho.
7. **Create repository** tap karo.

## B. Files upload karna (mobile app / browser)
1. Repository open karo.
2. **Add file** ya **+** option select karo.
3. **Upload files** choose karo.
4. ZIP ko extract karne ke baad project ke andar ki files upload karo. GitHub web upload mein folder ke andar ke files select karna zyada reliable hota hai.
5. Ye files/folder upload karo:
   - `file_integrity_checker.py`
   - `File_Integrity_Checker.ipynb`
   - `requirements.txt`
   - `README.md`
   - `PROJECT_REPORT.docx`
   - `tests/test_file_integrity_checker.py`
6. Commit message likho: `Add File Integrity Checker project by Muskan Sain`.
7. **Commit changes** tap karo.

**Note:** GitHub mobile app ke version ke hisaab se upload/create options alag jagah ho sakte hain. Agar app mein upload option na mile, Chrome mein `github.com` kholkar **Desktop site** enable karo aur upload steps follow karo.

## C. Repository check
1. Repository ke main page par README preview check karo.
2. Confirm karo ki saari 6 files/folder upload hue hain.
3. Notebook file par tap karke confirm karo ki GitHub preview open ho raha hai.
4. Repository ka URL copy karo; Google Form mein isi URL ko paste karna hai.

## D. Google Form submission
1. College/teacher ne jo official Google Form link diya hai, wahi open karo.
2. Form ke instructions poore padho.
3. Name field mein `Muskan Sain` likho.
4. Project title field mein `File Integrity Checker — Cybersecurity Project` likho.
5. Repository/GitHub URL field mein apne GitHub repository ka actual URL paste karo.
6. Agar file upload field ho, to faculty ke instruction ke hisaab se project ZIP ya report upload karo. Google sign-in aur file upload permission ki zaroorat ho sakti hai.
7. Required fields dobara check karo aur **Submit** dabao.
8. Confirmation message/screen ka screenshot le lo. Agar response edit link ya email receipt mile to sambhal kar rakho.

**Important:** Form link, required fields, deadline aur accepted file type college/teacher se verify karo. Koi actual Google Form URL ya repository URL is guide mein invent nahi kiya gaya hai.
